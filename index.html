기본 규칙 요약

  • HP는 생명력이자 카드 사용 비용. 회복은 최대 20까지. HP가 부족하면 카드를 쓸 수 없습니다.
  • 턴: 카드 1장 드로우 → 원하는 만큼 카드 사용 → 턴 종료. 같은 턴에 같은 이름의 카드는 사용 불가.
  • 처리 순서: 비용 지불 → 사용 선언 → 효과 해결 → 버림/소멸. 무효가 되어도 비용은 반환되지 않습니다.
  • 자기소멸 예외: 비용 지불로 HP가 0 이하가 되어도 그 카드가 즉시 HP를 1 이상으로 회복시키면 탈락하지 않습니다.
  • 피해 감소는 합산되며 최종 피해는 0 미만이 되지 않습니다. 지속 피해도 감소 효과를 받습니다.
  • 승리: 10라운드 종료 시 HP 1위. 공동 1위면 데스매치(HP 10, 모든 지속 효과 취소, 최후의 1인까지).
  • 조기 종료: 1명만 남으면 즉시 그 플레이어의 승리.
  • 덱 재구성: 덱이 소진되면 버린 카드 더미를 섞어 새 덱을 만듭니다(소멸 카드 제외).
  • 10라운드 종료 시 남아있는 모든 이월 피해·지연 효과(처벌의 처형 조건, 피의 디버프 등)를 즉시 처리합니다.
